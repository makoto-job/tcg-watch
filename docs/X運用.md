# X（Twitter）運用の手引き

このアカウントが存在する理由は1つ。
**「知っていれば応募できたのに」を無くすこと。**

情報量では既存の大手アカウント（フォロワー30万規模）に勝てません。
勝負するのは **「締切が近いものを、締切前に言う」** の一点です。

---

## アカウントの設計

### 名前の案

| 案 | 理由 |
|---|---|
| **TCGウォッチ｜抽選締切ナビ** | 「締切」を名前に入れる。他は「抽選情報」止まりなので差が出る |
| 今日締切のTCG抽選 | 用途がそのまま名前。検索で見つかりやすい |
| カード抽選リマインダー | 「思い出させる」役割を明示 |

**1案を推奨。** ブランド名（TCGウォッチ）と機能（締切）の両方が入るため。

### プロフィール文（そのままコピーできます・160字以内）

```
ポケカ / ワンピ / 遊戯王 / デュエマ / MTG / DBFW / ユニアリ など16タイトルの
抽選・予約情報を毎日まとめています。

「もう終わってた」を無くしたくて作りました。
締切が近い順に見られるアプリ↓（インストール不要）
```

**書かなかったこと**と、その理由。

- 「最速」→ 大手に勝てないので書かない。嘘は必ずバレます
- 「毎日◯件」→ 日によって変わるので書かない
- 絵文字の多用 → 情報アカウントは落ち着いた見た目のほうが信用されます

### 固定ポスト

```
このアカウントについて

・16タイトルの抽選/予約情報を毎日まとめています
・「締切が近い順」に並べているので、まだ間に合うものが分かります
・応募ページに直接飛べます（商品を探す手間がありません）

情報は各店の公式ページと公式発表から集めています。
応募条件・締切は必ず応募先でご確認ください。

アプリ（インストール不要）→ プロフィールのリンクから
```

**最後の1文が重要です。** 二次情報を含むため、最終確認を促すのは誠実さであると同時に自衛でもあります。

## 投稿の設計

### 何時に投稿するか

**12:00 を推奨**（現在の設定）。

理由は、抽選の告知が**午前中に出て、締切が夕方〜夜**というパターンが多いためです。
実データでも「10:00受付開始 → 当日20:00締切」の形が繰り返し観測されています。

朝一だと告知前、夜だと手遅れ。**昼が「気づいて動ける」時間帯**です。

### なぜURLを1つしか貼らないのか

**Xの料金が2026年2月から変わりました。**

```
投稿（URLなし）   15円
投稿（URLあり）  200円   ← 13倍
```

URLを含む投稿を増やすと、月2,800円かかります。
「Xには結論、リンクはアプリ」に徹すれば**月70円**です。

**この方針は変えないでください。** 40倍の差が出ます。

### ハッシュタグ

**3個まで。** 付けすぎると逆効果です（スパム判定・見た目が雑）。

その日のTOP3に出たジャンルのタグを自動で付けています。
`#抽選販売` は共通で入れると、抽選を探している人に届きます。

## 差別化：情報量では勝てないので、勝てるところで勝つ

### 競合の状況（`docs/競合分析.md` の要約）

| | 相手 | うち |
|---|---|---|
| 掲載件数 | 942件 | 50件 |
| ポケカ | 218件 | 21件 |
| LINE通知 | ✅ある | ❌まだ |
| Xフォロワー | 32万・25万 | 0 |

**正面から件数で戦うと負けます。**

### では何を言うか

**言うこと**

1. **「今日締切」を軸にする** — 相手は「受付中一覧」、こちらは「まだ間に合うもの」
2. **16タイトル横断** — 相手の多くはポケカ専門。ワンピ・遊戯王・デュエマ・ユニアリも見る人には価値がある
3. **応募の準備を助ける道具がある** — 住所コピー、店の登録チェックリスト。**競合5社とも持っていません**

**言わないこと**

- 競合の名前を出した比較（自分が小さいことを宣伝するだけ）
- 「最速」「最多」（事実でないため）
- 他アカウントへの言及全般

⚠️ **競合を攻撃してはいけない実務上の理由**があります。締切データの一部を、まさにその競合サイトから取得しています。攻撃は自分の情報源を断つ行為です。

## やってはいけないこと

| 禁止 | 理由 |
|---|---|
| 同じ文面の連投 | Xの自動化ルール違反。凍結対象 |
| 大量のメンション・リプライ | 同上 |
| 相互フォロー・フォロワー購入 | 数字だけ増えて意味がない。見る人にも分かる |
| 他人の投稿の無断転載 | 著作権。引用ならリンクを付ける |
| 「絶対当たる」等の断定 | 景表法。抽選情報で最もやってはいけない |
| アフィリエイトのPR表示なし | **ステマ規制（2023年10月〜）で違法** |

**自分のアカウントへの自動投稿はXの規約上OKです。** 上記に触れなければ問題ありません。

## 最初の30日

### 1週目：まず動かす

毎日12:00の自動投稿だけ。**手を加えない。**

見るのは1つだけ。**「投稿が毎日ちゃんと出ているか」**

### 2週目：反応を見る

- どのジャンルの投稿が伸びたか
- プロフィールのリンクが何回押されたか（Xのアナリティクスで見られます）

**フォロワー数は見なくていいです。** この段階では増えません。

### 3週目：手を入れる

反応が良かった形に寄せます。例えば「今日締切」を強調した投稿が伸びたなら、その形を増やす。

### 4週目：締切通知を試す

アプリ側に通知機能が入ったら、Xで告知します。
**これがフォローする理由になります。**「Xを見なくても教えてくれる」は強い。

## うまくいっているかの判断

**フォロワー数では判断しないでください。** 最初の数ヶ月はほぼ増えません。

見るべき指標:

| 指標 | どこで見るか | 意味 |
|---|---|---|
| **プロフィールのクリック数** | Xアナリティクス | 投稿を見た人が興味を持ったか |
| リンクのクリック数 | 同上 | アプリまで行ったか |
| リポスト数 | 同上 | 人に教えたくなったか（最重要） |

**リポストが一番大事**です。「役に立った」と思われた証拠で、拡散にも直結します。

### 伸びないときに疑う順番

1. **情報が遅い／間違っている** ← まずここ
2. 投稿が読みにくい（何の話か分からない）
3. 投稿時間が合っていない
4. フォロワーが少ない ← **最後**

多くの人が4から疑いますが、1〜3を直さずに数だけ追っても伸びません。
