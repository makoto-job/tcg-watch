# 抽選情報源の調査（2026-09-06）

## きっかけとなった指摘

> 抽選ページがオンラインショップじゃなくて、別ページ、隠しページみたいなのを
> 作ってるから、別の情報源を取る必要があるね。

**この指摘は正しく、それまでの調査方法が間違っていた。**

「店のトップページを開いてTCG商品があるか」で判断していたが、
抽選は通常の商品導線とは別のページで実施されている。

```
ヨドバシ           limited.yodobashi.com              別ドメイン
楽天ブックス        /event/game/card/entry/            イベント配下
プレミアムバンダイ   /hobby/lotterysales/               カテゴリ配下
ゲオ               /news/781（お知らせ記事）           ニュース欄
```

トップページに「ポケモンカード」の文字が無くても抽選はやっている。
**「TCG扱いなし」と判定した店の一部は誤判定の可能性がある。**

---

## 発見：抽選情報を横断集約しているサイトがある

1店ずつ当たるより、これらを見るほうが速く網羅的。
**bot拒否の店（ゲオ・ノジマ等）の情報もここから取れる。**

| サイト | URL | robots | 判定 |
|---|---|---|---|
| **ポケカ抽選図鑑** | `pokeca-navi.jp/lotteries/` | **Disallow 0件** | ⭕ **最有力**。店名145件・**締切表現670件** |
| **入荷Now** | `nyuka-now.com/archives/2459` | `/wp-admin/` `/campaign/` のみ | ⭕ 有力。店名56件・日付113件・随時更新 |
| カード抽選まとめ | `cardchusen.com` | **AIクローラ拒否あり** | ❌ **使わない**（情報量は最大だが方針を優先） |
| トレカの地図 | `torecamap.co.jp` | robots 404 | △ 発売日中心。店名0件 |

### ポケカ抽選図鑑が重要な理由

**締切表現が670件ある。** これは当botに最も欠けていたデータ。

記事本文を25件調べた結果、18件が「本文は読めるが締切が書いていない」だった。
店の商品一覧にも締切が無いことが多い（プレミアムバンダイの `TimerEnd` は例外）。
このサイトは締切を集約しているため、この穴を直接埋められる。

### 入荷Nowが拾っている店

```
抽選・予約応募受付中のストア
  ノジマオンライン / ポケモンカードゲーム公式 / HMVトレカショップ各店
  WonderGOO / 新星堂各店 / ジラフル各店 …
【在庫あり】先着販売・再販実施中のストア
```

**ノジマ（403でbot拒否）の情報がここから取れる。**

## 次にやること

1. **ポケカ抽選図鑑と入荷Nowを情報源に追加**（締切データの獲得が最優先）
2. honto・セブンネットの抽選/予約ページを特定
3. 取得できない店は `entryUrl` を登録して入口案内に回す
4. 「TCG扱いなし」と誤判定した店（イトーヨーカドー等）の再検証

## 守ること

- **AIクローラ拒否のあるサイトは使わない**（cardchusen.com、ローソンHMV）
- bot対策の回避はしない
- 集約サイトから取った締切も、**出典が確認できるものだけ** `applyVerified` を立てる
