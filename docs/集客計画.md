# 集客計画 — 最初の100人をどう取るか（2026-09-08 作成）

前提: アプリ未公開・Xアカウント未開設・利用者ゼロ。
**この文書は「公開初日に効かせる準備」であって、今日から客が増える話ではない。**

先に `docs/競合分析.md` を読むこと。**情報量では勝てない**という結論の上に立った計画である。

---

## フォローされる理由（1文）

> **他のアカウントは「抽選が始まりました」を流すが、ここは「今日の何時に締め切る、まだ間に合う枠」を流すから。**

これが言えなくなったら、この計画は全部やり直し。

補足として、なぜこの1文で足りるのか:

- 既存の速報アカウント（32.7万・25.8万フォロワー）は**開始**を流す。開始情報は
  大量に流れてきて、埋もれる。
- 応募する側が実際に困るのは**締切**。「知ってはいたが、気づいたら終わっていた」が
  取りこぼしの最頻パターン。
- 締切を締切順に持っているサイトはあるが、**Xで毎日「今日締切」を流す口**は空いている。

---

## 誰に届けるか

抽選に応募している層の中で、**一番困っているのは「そこそこ本気だが、専業ではない人」**。

| 層 | 状態 | 我々の価値 |
|---|---|---|
| 転売目的の専業 | 情報も自動化も自前で持っている | **無い。狙わない** |
| **兼業の熱心な人** | **1弾あたり数十件応募したい。仕事の合間に応募している。締切を落とす** | **大きい ← ここだけ狙う** |
| 子どもに買ってやりたい親 | 年数回。1件応募して外れて終わる | 中くらい（第2波で狙う） |
| ライトな遊び手 | 定価で買えたら嬉しい程度 | 小さい |

**兼業の熱心な人**に絞る理由:

1. 応募回数が多いので、**住所の再入力の苦痛が最大**（我々の中核機能が刺さるのはここ）
2. 締切を落とした経験が実際にある（痛みを自覚している）
3. 情報を人に勧める。転売目的の専業は情報を独占するが、この層は共有する

**この層の一日**: 昼休みか夜にまとめて応募する。だから **締切のリマインドは
「昼」と「夜21時ごろ」に意味がある**。朝の速報は彼らには届かない。

## 手段は人数によって変わる

同じ手が使えると思わないこと。10人と1000人では、まったく別のことをする。

### 最初の10人 — 一人ずつ、手で取る

この段階で**Xの投稿では1人も増えない**。フォロワー0のアカウントの投稿は誰も見ない。

| やること | 具体的に |
|---|---|
| **実際に応募している知人に直接見せる** | 3〜5人。「使ってみて」ではなく「**この画面のどこが分からないか教えて**」と聞く |
| **自分が使う** | 作者本人が毎日応募に使い、落ちた枠・間に合った枠を記録する。これが後の投稿ネタの原資になる |
| **作った理由を1本書く** | note か GitHub の README に。「締切を落として悔しかったから作った」という個人の話。宣伝文にしない |
| **PWAの入れ方を図で用意** | 「ホーム画面に追加」を知らない人が大半。ここで9割が脱落する。iPhone版・Android版の手順画像を先に作っておく |

**この10人から取るべきものはフォロワーではなく、"詰まった場所" である。**
10人が同じ場所で詰まるなら、100人配っても同じ場所で詰まる。

### 100人 — Xで「今日締切」を毎日出し続ける

ここで初めてXが効き始める。ただし**速報では戦わない**。

| やること | 具体的に |
|---|---|
| **投稿は「今日締切」だけ** | 1日1〜2回。昼12時と夜20時。「あと3時間で締め切る枠が4件あります」 |
| **リンクはプロフィール固定** | X APIは**URL付き投稿が$0.20（13倍）**。本文にURLを入れない。プロフィール欄のリンクは無料 |
| **固定ポストを作る** | 「このアカウントは何か」＋アプリの入れ方。プロフィールから来た人が最初に見る場所 |
| **検索で拾われる言葉を本文に入れる** | 「ポケカ 抽選 今日締切」「30th CELEBRATION 締切」。ハッシュタグではなく本文の語で |
| **質問に答える** | 「◯◯店の締切いつ？」に事実で答える。売り込まない。**返信は投稿より安く、信用が付く** |
| **落とした話を書く** | 「今日、自分は3件落としました」。完璧な情報源のふりをしない方が信用される |

**100人までは「毎日出す」以外に近道がない。** 30日続けて反応がゼロなら、
1文（フォローされる理由）が間違っているということなので、そこを直す。

### 1000人 — 検索と、他人の口

Xの手作業では1000人に届かない。ここからは**自分が寝ている間に見つかる仕組み**に移る。

| やること | 具体的に |
|---|---|
| **検索から取る** | GitHub Pages は Google にインデックスされる。Search Console にサイトマップを出す（無料）。狙う語は「ポケカ抽選 今日締切」「◯◯店 ポケカ 抽選 締切」 |
| **無料プレスリリース** | 競合（ポケカ抽選ナビ）が `pr-free.jp` に出して、実際に我々の観測に引っかかった。**同じ手が使える**ことが実証済み |
| **店舗に使ってもらう** | 掲載されている店に「載せています」と伝える。店側は告知が広まるので利害が一致する。トレカの地図はすでに店舗側を取りにいっている |
| **道具として紹介される** | 「住所を打ち直さずに応募できる」は記事にしやすい。情報サイトは競合を紹介しないが、**道具は紹介される**（競合サイトにとって我々は集客の敵ではなく便利機能だから） |
| **他TCGに広げる** | ポケカでは件数で勝てない。遊戯王・デュエマ・ヴァンガードは競合の掲載も薄い。**掲載0件を埋める方が、ポケカで22→50件にするより効く** |

## X以外の経路

**ある。しかも1000人の段階ではXより重要になる。**

| 経路 | 使えるか | 根拠・注意 |
|---|---|---|
| **Google検索** | **◎ 最重要** | GitHub Pages は静的HTMLでインデックスされる。競合は全社ここから客を取っている |
| **無料プレスリリース**（pr-free.jp / prerele.com 等） | **○** | 競合の実施例あり。費用0円。ただし1回きりの効果 |
| **note / 個人ブログ** | ○ | 「作った理由」「落とした話」を置く。Xの固定ポストから飛ばす先になる |
| **店舗への直接連絡** | ○（中期） | 掲載している店に伝える。相手にも利がある |
| Discord / 掲示板 | **△ 条件付き** | サーバー規約を読み、**宣伝可の場所で、運営に許可を取ってから**のみ。無断投稿はしない |
| LINE公式アカウント | △（将来） | 競合はここで通知をやっている。ただし通知機能が出来てからの話 |
| App Store | **×** | 我々はPWA。ストアには並ばない。**「ホーム画面に追加」の説明が生命線** |
| YouTube / TikTok | × | 作る手が無い。1日30分では回らない |

**PWAであることは、配布経路として明確な弱点。**
入荷Nowはストアに並んでいて検索で見つかるが、我々は見つからない。
これは「ホーム画面に追加」の説明を、アプリの一等地に置くことでしか埋まらない。

## 測る指標

**フォロワー数は最後に見る。** 増えても使われていなければ意味がない。

### 取れる数字（無料で計測できるもの）

| 指標 | 取り方 | 1ヶ月後の目安 |
|---|---|---|
| **プロフィールクリック数** | X Analytics（無料） | **これが最重要**。投稿を見た人のうち何人がアプリを見に来たか |
| インプレッション | X Analytics | 100人フォロワー時点で1投稿1,000前後 |
| **検索の表示回数・クリック数** | Google Search Console（無料） | 4週目までに表示が出始めれば正常 |
| 返信・引用の数 | 目視 | **1件でも来たら大きい**。会話が起きているかどうか |
| 締切データの件数 | `public/feed.json` を数える | 現在27件。ここが減ると価値が落ちる |

### 取れない数字（正直に認めること）

**GitHub Pages にはアクセス解析が無い。** サーバーログが見えないため、以下は測れない。

- アプリを開いた人数
- ホーム画面に追加した人数
- マイ情報のコピーが使われた回数（**そもそも端末内で完結する設計なので、原理的に取れない**）

これは弱点ではなく設計の結果である。「どこにも送らない」と言い切るために捨てた数字。
**代わりにプロフィールクリック数を、利用者数の代理指標として使う。**

### 成功・失敗の線引き（公開1ヶ月後）

| | 判定 |
|---|---|
| プロフィールクリックが週50以上 | **1文が効いている。継続** |
| 返信・引用が月3件以上 | **道具として認識された。継続** |
| フォロワーが増えているがプロフィールクリックが週10未満 | **見られているが刺さっていない。1文を書き直す** |
| インプレッションが1投稿100未満のまま4週 | **届いていない。投稿時間か言葉を変える** |
| 検索表示が0のまま4週 | **インデックスされていない。技術側の問題として他部署へ** |

## この計画がうまくいかない場合に疑う順番

1. **1文が間違っている**（「今日締切」に需要が無い）→ 最初に疑う
2. **投稿時間が合っていない**（昼夜ではなく朝だった）
3. **PWAの入れ方で脱落している**（アプリに辿り着けていない）
4. **締切データが薄い**（27件では毎日投稿するネタが足りない）← 実際に起こりうる
5. フォロワーが足りない ← **これは最後**。ここから疑い始めると必ず失敗する

## やらないこと（禁止）

以下は短期的に数字が動いても、**信用を失うと二度と戻らない**ので一切やらない。

- 相互フォロー、フォロー返し目的のフォロー
- フォロワーやいいねの購入
- 他人の投稿・他サイトの文章の無断転載
- 競合サイトへの言及による攻撃・比較批判
- 関係を明かさない推奨（ステマ）
- Discord・掲示板への無断の宣伝投稿

特に **競合への攻撃は絶対にしない**。
我々は締切データの74%をポケカ抽選図鑑から得ている。攻撃する相手ではない。
