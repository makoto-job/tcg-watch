Roadmap

カードゲーム抽選アプリを、
どう育てて、いくら稼ぐか

お金・時間・順番を、正直な数字で整理しました。盛っていません。うまくいかない可能性も書いています。

さいしょに結論

これは「1年で月5〜6万円」を目指す仕事です。
いきなり大きく儲かる話ではありません。

ただし元手がほぼゼロ（月70円〜）なので、失敗しても失うのはお金ではなく時間だけです。そして本当のチャンスは、同じ仕組みをスニーカーやフィギュアの抽選にも横展開できるところにあります。そこまで行けば桁が変わります。

そもそも、どうやってお金になるの？

how it earns
たとえるなら「お店の案内係」です。
あなたはカードを売りません。「あの店で今、抽選やってるよ」と教えてあげます。教えてもらった人がその店で買うと、お店から少しだけお礼のお金がもらえます。これがアフィリエイトです。
お金の入り方しくみ1件あたり
アフィリエイト
いちばん本命		アプリのリンクから買ってもらうとお礼がもらえる150〜600円
広告アプリに広告を置く1000回見られて200円
有料の早出し通知「抽選が始まる前に教える」を月額にする300円/月・人
お店とのタイアップカードショップに宣伝してもらう規模が出てから
ここは要注意。 抽選は「応募」であって「買った」ではありません。当選して、実際に買われて、はじめてお礼のお金が発生します。 だから「応募数」ではなく「当選して買った人の数」が売上になります。予約や通常販売のほうが、実はお金になりやすいです。

では「月20万円」の中身は？

フェーズ5（フォロワー2〜3万・アプリ利用者5,000人）を分解すると、こうなります。

収入源月額割合
アフィリエイト約8.6万円45%
有料プラン（月額課金）4.5〜7.5万円30%
タイアップ広告約3万円15%
広告（AdSense）約8千円5%
広告では稼げません。ここは誤解しやすいところです。
日本のディスプレイ広告は1,000回見られて約200円。利用者5,000人×月8ページ＝4万PVでも8,000円にしかなりません。広告で20万円稼ぐには月100万PVが必要で、この規模では届きません。
Xのインプレッション収益も同様に期待できません（直近3ヶ月で数百万インプレッションという条件があり、桁が足りません）。
本当の主力は、アフィリエイトと月額課金です。
つまりこれは「広告で稼ぐメディア」ではなく、「買いたい人を店につなぐ案内所＋月額サービス」です。
だから大事なのはPV数ではなく「買う気がある人が何人いるか」。1万人の暇つぶし読者より、500人の「今すぐ買いたい人」のほうが稼ぎます。
アフィリエイトの計算根拠
利用者5,000人 → クリック8,000回 → 実際に買う人3%＝240件 → 平均単価12,000円 × 報酬率3% ＝ 86,400円/月

横展開で伸びるのはここです。TCGのBOXは5,000〜20,000円ですが、スニーカーは15,000〜30,000円、フィギュアも1万円超。同じクリック数でも売上が跳ねます。
法律上の必須事項。 2023年10月からステマ規制（景品表示法）が施行されており、アフィリエイトリンクには「広告」「PR」の表示が義務です。表示が無いと法令違反になります。実装時に必ず入れます。

どれくらいの規模になりそう？

honest numbers

フォロワーが増えると、アプリを使う人が増え、買う人が増えます。仮の数字ですが、こんなイメージです。

時期フォロワーアプリ利用者月の売上
3ヶ月後300〜1,00050〜100人ほぼ0円
6ヶ月後1,000〜3,000200〜300人約1万円
1年後5,000〜10,0001,000〜1,500人約6.5万円
2年後（横展開すれば）2〜3万5,000人〜20万円〜
正直に言うと、これは「うまくいった場合」です。 同じことをやっている人はすでにいます（実際、今日集めたニュースの中に「ポケカ抽選ナビ」という競合サービスの開店告知が入っていました）。勝てなければフォロワー数百人で止まります。 勝負どころは1つだけ、「誰よりも早いこと」です。

本当のコストはお金ではなく「時間」です。
毎月2〜5時間くらい。何をするかというと、公式サイトの作りが変わったときの直しです。相手の都合で急に情報が取れなくなるので、そこだけは人の手が要ります。

どうやって届けるか

the install problem

「ストアを通さないアプリを入れてもらえるのか？」という問題があります。結論から言うと、入れてもらえません。だからインストールを要らなくします。

　AndroidiPhone
インストールのボタンちゃんと出る出ない
手順1タップSafariで開く→共有→ホーム画面に追加
他のブラウザ—Chromeでは不可能

Appleは意図的にこの導線を目立たせていません。日本はiPhone比率が高いので、他の国より深刻です。

そもそも、何のためにインストールが必要なのでしょう？
答えは1つだけ、通知を送るためです。それ以外は、ただのWebページで全く同じことができます。
つまり目的は「インストールさせること」ではなく「締切を知らせること」。だったら、みんながすでに持っているアプリを使えばいい。

インストールを要求しない4層構造

層手段インストール届く相手
0Xの投稿不要フォロワー全員
1Webページ不要リンクを押した人全員
2LINE公式アカウント不要友だち追加した人
3ホーム画面に追加必要ヘビーユーザーのみ
鍵は層2のLINEです。
日本人のほぼ全員がLINEを持っています。友だち追加はワンタップ、インストール不要で、プッシュ通知が届きます。 iPhoneのホーム画面追加問題を丸ごと回避できます。
LINEのプラン送れる数月額
無料プラン200通0円
ライトプラン5,000通数千円
スタンダードプラン従量課金あり15,000円
LINEは使い方を間違えると破産します。 1,000人に一斉送信すると1,000通消費します。毎日の情報をLINEで流してはいけません。

正しい使い分け
・毎日の情報 → X と Web（無料）
・締切が迫った緊急のものだけ → LINE
・さらにセグメント配信で「ポケカ希望の人だけ」に送れば通数を大幅に減らせます
いちばん大事な実装ルール：インストールを最初に頼まないこと。

❌ 開いた瞬間に「ホーム画面に追加してください」
　　→ まだ何の価値も受け取っていないので、怪しいと思われる

⭕ まず普通にWebページとして使ってもらう → 実際に抽選ページへ飛べて役に立った → そのタイミングで初めて「締切を通知します。LINEで受け取りますか？」

言葉選びも大事です。「アプリをダウンロード」と言うと警戒されます。実際にはダウンロードではなくブックマークを置くだけなので、「ホーム画面に置く」と言うだけで抵抗感が変わります。
ストアアプリを今つくらない理由。
① Appleの審査ガイドライン4.2（Minimum Functionality）は、Webサイトを包んだだけのアプリを明確に却下します。ニュースまとめ系は典型的なリジェクト対象です。
② Apple Developer Program は年15,000円、審査は数日〜数週間、落ちたらやり直し。
③ ストアに出しても誰も見つけません。流入はどのみちXからです。

ストアアプリはフェーズ4〜5、「通知を求める人が確実にいる」と分かってからで十分です。

いちばん大事なこと

the one thing
勝負は「速さ」だけです。
デザインでも機能の多さでもありません。「あのアカウントを見ていたから抽選に間に合った」という体験を1回でも作れれば、その人は一生フォローを外しません。逆に、いくら機能が多くても遅ければ意味がありません。

だからフェーズ2の締切通知が、このロードマップで一番重要な項目です。
やめたほうがいいこと。 自分の投稿をニュースに紛れ込ませるのは避けてください。抽選情報のアカウントは信頼が全てです。載せるなら「自分の投稿」と分かる表示を付けてください。
