## いま何ができるの？

### ✅ できていること

**1. 情報を自動で集める**

35個のサイトを自動で見に行きます。

- カードゲームの公式サイト（ポケモン・ワンピース・遊戯王など17個）
- お店（楽天ブックス・カードラボ・ミント・ファミマなど18個）

1回まわすと**396件**の情報が集まります。

**2. 「いつまでに応募すればいいか」が分かる**

```
あと0時間  [文教堂書店浦安西友店]  30th CELEBRATION BOX
あと1時間  [カードボックス日本橋店] ストームエメラルダ
あと2時間  [SuperKaBoS敦賀店]     ストームエメラルダ
```

**3. 応募ページに直接飛べる**

商品を探す手間がありません。ボタンを押すとお店の応募ページが開きます。

**4. アプリの画面**

スマホで見やすい画面ができています。ジャンルで絞ったり、締切の近い順に並べ替えたりできます。

**5. 会員登録の準備を助ける**

抽選に落ちる人の多くは「当日に会員登録から始めて間に合わない人」です。
そこで、住所や名前をコピーできる機能と、「どのお店に登録済みか」のチェックリストを作りました。

### ❌ まだできていないこと

| やりたいこと | 状態 |
|---|---|
| **誰でも見られるURL** | ❌ まだ公開していない |
| **締切のお知らせ（通知）** | ❌ これが一番ほしい機能 |
| 検索 | ❌ |
| お金を稼ぐ仕組み | ❌ 後回しと決めた |

## 見つかった問題と、直したこと

### 直したもの

| 問題 | どうなっていたか |
|---|---|
| **締切が間違っていた** | 「応募できる」と出していたのに、押したら期間外だった |
| **売り切れが出ていた** | 買えない商品を出していた |
| **古い情報が残っていた** | お店が「4箱まで」に変えたのに「6箱まで」と出していた |
| **別のお店の抽選をまとめていた** | 同じ商品名だと1つにされ、応募先が減っていた |
| **ジャンルが偏っていた** | ポケモンばかりで、ドラゴンボールなどが消えていた |

### いま直している最中

- ジャンルのバッジが消える問題（ドラゴンボールなど）
- 情報が取れていないサイト10個

## 大事にしている考え方

**まちがった情報を出すぐらいなら、何も出さないほうがマシ。**

「あと3時間で締切」と書いてあって、押したら終わっていた——これが一番やってはいけないことです。
抽選のアプリは、1回でも裏切ると使われなくなります。

だから、

- 確実でない締切は**出しません**
- お店の商品ページに飛べないときは、**お店の入口だけでも案内**します
- ボタンの文字を「応募」「確認」「探す」と変えて、**押す前に何が起きるか分かる**ようにしています
