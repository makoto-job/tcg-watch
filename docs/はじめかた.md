# はじめかた（1週間・1日30分）

このツールを「自分のパソコンの中だけで動くもの」から
「インターネット上で勝手に動き続けるもの」に変えるまでの手順です。

**1日ぶんずつやってください。まとめてやらなくて大丈夫です。**

---

## 全体の流れ

```
1日目  置き場所を作る（GitHub）
2日目  ホームページとして公開する      ← ここでURLが手に入る
3日目  Xに投稿する権利をもらう
4日目  カギを登録する
5日目  はじめての投稿
6日目  自動で動くようにする
7日目  iPhoneに入れて完成
```

---

## 1日目：置き場所を作る（30分）

インターネット上に、プログラムを置く「棚」を作ります。無料です。

### ① GitHubに登録する

https://github.com/signup

メールアドレスとパスワードを決めるだけです。すでに持っていれば飛ばしてください。

### ② 棚を1つ作る

https://github.com/new を開いて、こう入力します。

| 入力するところ | 何を入れるか |
|---|---|
| Repository name | `tcg-watch` |
| Public / Private | **Public**（公開）を選ぶ |
| Add a README file | **チェックしない** |
| Add .gitignore | **なし**のまま |
| Choose a license | **なし**のまま |

⚠️ **下3つのチェックを外すのを忘れないでください。** 入れてしまうと次の手順で失敗します。

「Create repository」を押すと完成です。

> **「Publicだと中身が全部見られちゃうのでは？」**
> プログラムは見られますが、**パスワードやカギは入っていません**。
> カギは別の場所（次で説明するSecrets）に隠して置きます。これが普通のやり方です。
> Privateにすると、無料で使える時間に上限ができて足りなくなります。

### ③ 中身を送る

作った直後の画面に出てくる、あなたのアドレスをコピーしてください。
`https://github.com/あなたの名前/tcg-watch.git` という形です。

Macのターミナルで、以下を1行ずつ実行します。
（`あなたの名前` の部分は自分のものに置き換えてください）

```bash
cd /Volumes/mac_2TB/tcg-watch
```

```bash
git remote add origin https://github.com/あなたの名前/tcg-watch.git
```

```bash
git push -u origin main
```

パスワードを聞かれたら、GitHubのパスワードではなく
**Personal Access Token**（アクセス用のカギ）が必要です。
https://github.com/settings/tokens で「Generate new token (classic)」を押し、
`repo` にチェックを入れて作ったものを貼り付けてください。

**GitHubのページを再読み込みして、ファイルが並んでいれば1日目は完了です。**

## 2日目：ホームページとして公開する（20分）

ここでURLが手に入ります。**いちばん嬉しい日です。**

### ① 公開をオンにする

自分のリポジトリのページで、

**Settings**（歯車）→ 左メニューの **Pages** → Source を **GitHub Actions** に変える

### ② 動くのを待つ

上の **Actions** タブを開くと、作業が動いているのが見えます。
オレンジの丸が緑のチェックに変わるまで、2〜3分待ってください。

### ③ URLを開く

```
https://あなたの名前.github.io/tcg-watch/
```

**iPhoneのSafariでも開いてみてください。**
Claudeのアプリに邪魔されることなく、普通に開きます。

## 3日目：Xに投稿する権利をもらう（30分）

### ① 電話番号を登録する

投稿させたいXアカウントで、設定 → セキュリティ → 電話番号 を登録します。
**これがないと次に進めません。**

### ② 開発者として登録する

https://developer.x.com/ →「Sign up」

英語で「何に使いますか」と聞かれます。以下をそのまま貼ってください。

```
I am building a personal bot that collects public news about Japanese
trading card games (Pokemon TCG, One Piece Card Game, Yu-Gi-Oh) from
public RSS feeds and official websites, and posts a daily summary to my
own account. It does not interact with other users, does not send
direct messages, and does not scrape user data.
```

### ③ アプリを作る

「Projects & Apps」→「Create App」→ 名前を決める（世界で1つだけの名前）

**⚠️ ここがいちばん間違えやすいところです**

1. **User authentication settings** の「Set up」を押す
2. **App permissions** を **Read and write** に変える
3. Type of App は **Web App, Automated App or Bot**
4. Callback URI に `https://example.com/callback`
5. Website URL に `https://example.com`
6. 保存する
7. **保存したあとで**「Keys and tokens」を開き、
   **Access Token を「Regenerate」（作り直し）する**

**7番を忘れると投稿できません。**
カギは「作った時の権限」を持ち続けるので、権限を変えたら作り直しが必要です。
作り直したあと `Created with Read and Write permissions` と出ていればOKです。

### ④ 4つの値を控える

- API Key
- API Key Secret
- Access Token
- Access Token Secret

**この画面を閉じると二度と見られません。** メモアプリに貼っておいてください。

## 4日目：カギを登録する（20分）

### ① 自分のパソコンに登録する

```bash
cd /Volumes/mac_2TB/tcg-watch && cp .env.example .env
```

`.env` というファイルを開いて、昨日の4つの値を貼ります。

```
X_API_KEY=（ここに貼る）
X_API_SECRET=（ここに貼る）
X_ACCESS_TOKEN=（ここに貼る）
X_ACCESS_TOKEN_SECRET=（ここに貼る）
```

⚠️ **クォート（"）で囲まないでください。** 前後に空白も入れないでください。

### ② つながるか試す

```bash
cd /Volumes/mac_2TB/tcg-watch && npm run auth-check
```

自分のアカウント名が出れば成功です。

エラーが出たら:
- **401** → カギの写し間違い。空白が混ざっていないか確認
- **403** → 3日目の⑦（作り直し）を忘れている

### ③ GitHubにも登録する

リポジトリの **Settings** → **Secrets and variables** → **Actions**
→「New repository secret」で、4つを1つずつ登録します。

名前は `.env` と同じ（`X_API_KEY` など）にしてください。

**この場所に入れたものは、誰にも見えません。** だからPublicでも安全です。

## 5日目：はじめての投稿（30分）

### ① 何が投稿されるか見る

```bash
cd /Volumes/mac_2TB/tcg-watch && npm run preview
```

投稿される文章がそのまま表示されます。**まだ投稿はされません。**

内容を読んで、変な記事が入っていないか確認してください。

### ② 実際に投稿する

納得できたら、

```bash

```

Xを開いて、ちゃんと投稿されているか確認してください。

## 6日目：自動で動くようにする（20分）

### ① 書き込みを許可する

**Settings** → **Actions** → **General** → 下のほうの **Workflow permissions**
→ **Read and write permissions** を選んで Save

**これを忘れると、自動更新が毎回失敗します。**

### ② 手で1回動かしてみる

**Actions** タブ →「TCG bot daily」→「Run workflow」

緑のチェックがつけば成功です。

これで以下が**勝手に**動きます。

| いつ | 何が起きるか |
|---|---|
| 昼8時〜24時 | 30分ごとに新しい情報を集める |
| 深夜 | 1時間ごとに集める |
| 毎日12時 | Xにその日のTOP3を投稿 |

## 7日目：iPhoneに入れる（20分）

### ① Safariで開く

```
https://あなたの名前.github.io/tcg-watch/
```

**必ずSafariで開いてください。** Chromeではこの先ができません。

### ② ホーム画面に置く

1. 画面の下にある**共有ボタン**（四角に↑）を押す
2. 下にスクロールして「**ホーム画面に追加**」
3. 「追加」を押す

アイコンが増えていれば完成です。

### ③ 翌日、確認する

次の日にアプリを開いて、
**「最終更新」の時刻が新しくなっていれば、全部うまくいっています。**

## 困ったときは

| 症状 | 見るところ |
|---|---|
| pushでパスワードが通らない | Personal Access Token を使う（1日目③） |
| ページが真っ白 | Settings → Pages が「GitHub Actions」になっているか |
| 投稿が403で失敗 | Access Token を作り直したか（3日目⑦） |
| 自動更新が失敗する | Workflow permissions が Read and write か（6日目①） |
| 情報が更新されない | Actions タブでエラーが出ていないか |

うまくいかないところは、**エラーの文章をそのまま伝えてください。** 一緒に直します。
